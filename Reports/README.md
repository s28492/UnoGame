# Katalog `UnoGame/Reports` – Logi i Zagregowane Raporty

Katalog przeznaczony na automatycznie wygenerowane dane z symulacji gier w formacie JSON oraz statystyczne zestawienia wyników.

## 📄 Zawartość Katalogu

- **`game_report_*.json`** – Próbki raportów z pojedynczych symulacji zawierające przebieg tura po turze, użytych botów oraz wygranego.
- **`aggregated_reports.json`** – Zagregowane metryki zbiorcze ze skumulowanych serii rozgrywek.
- **`statistical_results.txt` / `historical_analysis.json`** – Wyniki przetworzone przez moduły z katalogu `Analysis`.
