# Moduł `Uno/Analysis` – Analiza Statystyczna i Ewaluacja Wyników

Moduł zawiera narzędzia do analitycznej obróbki wygenerowanych raportów i logów rozgrywek.

## 📄 Zawartość Modułu

- **`analyze_history.py`** – Skrypt przetwarzający zapisane pliki JSON z historią rozgrywek w celu wyliczenia wskaźników Win Rate, średniej długości gry i częstotliwości zagrań.
- **`statistical_tests.py`** – Skrypt wykonujący testy istotności statystycznej (np. test Chi-kwadrat, ANOVA / T-test) porównujące skuteczność poszczególnych botów.
