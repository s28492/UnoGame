# Moduł `Uno/QLearning` – Uczenie ze Wzmocnieniem (Reinforcement Learning)

Moduł przeznaczony na implementację i utrzymanie agentów opartych na algorytmie Q-Learning (oraz potencjalnych rozszerzeniach głębokiego uczenia ze wzmocnieniem - Deep Q-Learning / DQN).

## 📄 Zawartość Modułu

- **`__init__.py`** – Plik inicjalizujący moduł uczenia ze wzmocnieniem dla gry Uno.
- Integracja z klasą `QlearningBot` zlokalizowaną w pakiecie `AIPlayers`.
